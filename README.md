# re-habita

Static vintage furniture storefront inspired by editorial design stores.

## Local preview

Double-click `START_WEBSITE.cmd`, or run:

```powershell
node server.js
```

Then open:

```text
http://127.0.0.1:4173
```

## Vercel

This project is a static website. Import the GitHub repository in Vercel and use the default static settings:

- Framework preset: Other
- Build command: None
- Output directory: `.`
